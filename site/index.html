Browser extension for the Divi blockchain

IronDivi Wallet

Keep DIVI in your browser, switch between mainnet and testnet, and approve what Divi sites ask for, one request at a time. Your keys are made and kept encrypted on your own computer.

Download Install steps

Chrome, Brave, Edge, Opera, Firefox and Safari on desktop. Not in the browser stores yet: store listings are coming.

Works with Divi Games.

What it does

A small wallet that does the Divi basics well and asks you before anything leaves it.

  • One recovery phrase

    An HD wallet from a 12 or 24 word recovery phrase. The same phrase gives you a D address on mainnet and a y address on testnet.

  • Several accounts

    Create a new wallet or import an existing recovery phrase, name each account, and switch between them from the popup header.

  • Mainnet and testnet

    Both Divi networks in one build. It starts on testnet, and switching network asks for your wallet password, so a stray click can't put you on real DIVI.

  • Approve every request

    Sites ask to connect, sign a message or send a payment. Each one opens an approval window showing the site, the network and the details. Signing and sending need your password.

  • Spending limits

    By default one send can move at most 10% of your balance. Change the percentage or set a fixed DIVI cap in Settings.

  • Address book

    Save contacts with a name and notes. The Send screen suggests them as you type, so you paste addresses less.

  • History with confirmations

    Payments appear as soon as they reach the network, count up from 0/6 to 6/6 confirmations, and link to the Divi explorer.

  • Allowed sites only

    The wallet only talks to sites on your Allowed Sites list. Out of the box that's only games.divi.domains, named exactly with no wildcard. You can edit it; adding a site asks for your password.

  • Receive and test coins

    Share your address as text or a QR code. On testnet a faucet button gets you free test DIVI to try things with.

You can always tell which network you're on

Mainnet is real money; testnet is for trying things out. The wallet gives each its own colour, the same ones services.divi.domains uses, across the header, the logo, the network badge and the approval window.

Install

IronDivi Wallet isn't in the Chrome Web Store, Firefox Add-ons or the Mac App Store yet; store listings are coming. Until then you install it yourself from the file below. It takes a couple of minutes.

Chrome

File: the Chrome .zip in /downloads/

Download for Chrome
  1. Download and unzip. Unzip it into a folder you'll keep, for example Documents/IronDivi Wallet. Chrome runs the extension from that folder, so don't delete or move it later.
  2. Open the extensions page. Type chrome://extensions in the address bar and press Enter.
  3. Turn on Developer mode with the switch at the top right.
  4. Click “Load unpacked” and choose the unzipped folder, the one that contains manifest.json.
  5. Pin it. Click the puzzle-piece icon in the toolbar and pin IronDivi Wallet so it's one click away.

Upgrading later

Unzip the new version into the same folder, replacing the old files, then press Reload (↻) on the extension's card in chrome://extensions. Your wallet is kept. Removing the extension, or loading the new version from a different folder, starts you with an empty wallet, and only your recovery phrase brings your accounts back.

Firefox 128 or newer

File: the Firefox .xpi in /downloads/

Download for Firefox

Mozilla has signed the add-on, so Firefox installs it like any other.

Install

  1. Download the .xpi and save it somewhere you can find it.
  2. Open about:addons, click the gear button and choose “Install Add-on From File…”, then pick the .xpi. Dragging the file onto a Firefox window does the same.
  3. Click Add when Firefox asks. The wallet's icon appears under the puzzle-piece button; pin it to the toolbar from there.

Upgrading later

Download and add the new version the same way. Firefox replaces the old one and keeps your wallet.

The add-on isn't signed by Mozilla yet, so Firefox won't install it permanently.

Try it now (temporary)

  1. Download the .xpi and save it somewhere you can find it. Firefox may offer to install it straight away and then refuse because it's unsigned; that's expected, use the steps below.
  2. Open about:debugging#/runtime/this-firefox in the address bar.
  3. Click “Load Temporary Add-on…” and pick the .xpi file.

A temporary add-on is removed when Firefox restarts, and its wallet data may go with it. Write your recovery phrase down before you put anything in it.

Keep it installed

Wait for the Mozilla-signed add-on: this page will offer it as soon as Mozilla signs it. Don't turn off Firefox's signature check to install this one: that would let any unsigned add-on in.

Safari macOS, Safari 17 or newer

File: the Safari .zip in /downloads/

Download for Safari

Safari extensions come inside a small Mac app. This build isn't signed by Apple yet, so Safari needs to be told to allow it.

  1. Download and unzip. You get IronDivi Wallet.app. Move it to your Applications folder.
  2. Open the app once so macOS registers the extension. If macOS says it's from an unidentified developer, right-click the app and choose Open, or go to System Settings → Privacy & Security and click Open Anyway.
  3. Show the developer settings. In Safari, open Settings → Advanced and tick “Show features for web developers”.
  4. Allow unsigned extensions. In Settings → Developer, tick “Allow unsigned extensions”. Safari turns this off every time it quits, so you'll need to tick it again after each restart.
  5. Turn it on. In Settings → Extensions, enable IronDivi Wallet and allow it on the websites you want to use it with.

Check your download

Each file's SHA-256 checksum is listed below. Compare it with the one your computer calculates; if they don't match, don't install the file.

macOS or Linux, in Terminal

shasum -a 256 irondivi-wallet-chrome-v0.0.6.zip

Windows, in PowerShell

Get-FileHash irondivi-wallet-chrome-v0.0.6.zip -Algorithm SHA256

Run the command in the folder you downloaded to (usually Downloads). The commands above follow the browser you picked under Install.

Security and status

Beta

Testnet first. IronDivi Wallet is open source and has had an internal adversarial security review, and every critical, high, medium and low finding it raised has been fixed. It has not had an external audit. Don't keep significant mainnet funds in it yet.

Read the source on GitHub

  • Keys stay on your computer

    Your recovery phrase and keys are generated in the extension and stored encrypted with your password (PBKDF2 with 600,000 iterations, then AES-GCM). They are never sent anywhere.

  • You approve what sites do

    A site can only reach the wallet if it's on your Allowed Sites list. Connecting opens an approval window; every signature and payment opens one too, and needs your password. Ignore it for 5 minutes and it's rejected.

  • Networks look different

    Mainnet is red and testnet is indigo, everywhere in the wallet, and changing network asks for your password.

  • Your recovery phrase is the backup

    Write it down on paper and keep it somewhere safe. Nobody, including the people who make this wallet, can recover it or your password for you.

Questions

Why isn't it in the Chrome Web Store or Firefox Add-ons?

It's still in beta. Store listings are coming; until then, install it from the files on this page using the steps for your browser.

Can I use it on my phone?

No. It's an extension for desktop browsers: Chrome, Brave, Edge, Opera and Firefox on Windows, macOS and Linux, and Safari on macOS.

Which network does it start on?

Testnet. Get free test DIVI from the faucet button on the Receive screen, try things out, and switch to mainnet from the network badge or Settings when you're ready.

I forgot my password. What now?

The password can't be recovered, but your accounts can. Add an account with “Import Recovery Phrase”, enter your phrase, and choose a new password. Without the recovery phrase there is no way back in.

Will updating erase my wallet?

Not if you update in place. On Chrome, Brave, Edge and Opera, unzip the new version over the old folder and press Reload on the extension's card. Removing the extension, or loading it from a different folder, starts an empty wallet. Keep your recovery phrase either way.

Can I use the same wallet in two browsers?

Yes. Install the extension in each one and import the same recovery phrase.

Which sites can use it?

Sites on your Allowed Sites list, which starts as games.divi.domains alone. That covers Divi Games. The IronDivi web wallet at services.divi.domains is a wallet of its own and does not need this one. The wallet talks to sites through its own window.irondivi provider, not WalletConnect.
